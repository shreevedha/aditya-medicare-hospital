# Aditya Medicare Hospitals Website

Open this project in VS Code using **File > Open Folder**.

## Run locally
1. Open the full project folder in VS Code.
2. Open `index.html`.
3. Click **Go Live** using Live Server.

## Important files
- `index.html` = main website structure and sections
- `style.css` = design, spacing, doctor card sizes, responsive layout
- `script.js` = doctor database, department filters, profile popup, appointment modal
- `images/doctors/` = doctor photos
- `images/` = hospital image and diagnostic equipment images
